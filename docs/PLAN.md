# 麦麦一起点

孩子慢慢选，家长接着买。

## 首版目标

面向培智学校学生与其家长、监护人、教师的点餐沟通原型。学生用图片和短语音表达想吃什么，家长接手核对官方餐品、门店、价格并完成购买。当前没有安排外部学生试用，不声称已证明独立使用能力或减负效果。

## 流程

1. 家长确定门店，从真实菜单中准备少量单品。
2. 学生每屏看三张图卡，听名称、选择或取消；不倒计时，不判对错，不自动跳页。
   - 语音沿用培智案例的 MiniMax 音色；图卡或“听一听”支持鼠标悬停朗读，触屏点按播放。听读不加入清单。
   - 可乐的普通／无糖、杯型和饮料冰量按官方选项逐步展开；选项点击不自动跳步。可以确认当前选择，也可以标记“和家长一起选”，由家长确认后核价。
3. 已选托盘始终可见，可回看、改选、求助，允许某一类不选。
4. 学生确认意愿后，同设备交给家长。家长看到图片与官方名称、规格、冰量、数量、价格；原始规格保留，变更记录主体和前后内容，修改后旧报价失效。
5. 通过真实 MCP 核价；家长明确确认后才创建订单。付款在官方页面由成年人手动完成，状态以官方查询为准。

## 两种运行方式

- 公开演示：静态网页、示例菜单与示例价格，完整体验选择和接手，不创建真实订单。
- 本机连接：Token 保存在服务端，通过官方 MCP 查询门店、菜单、核价、创建和查询订单。

## 设计参考

沿用既有学校案例的米白底、深蓝描边、清晰图卡、短语音和可见选中状态；不复制学校内部素材，不继承答题、积分、倒计时和答错重试机制。界面使用符合学生年龄的平等用语。

## 范围

首版仅同设备交接、到店自取、单品及已适配的普通饮料选项。当前支持官方返回的可乐单轮规格与冰量，不能把所有带选项的商品一概过滤成套餐，也不虚构官方未提供的规格。暂不做复杂套餐定制、配送、跨设备同步、学生档案、优惠券优化、营养评估或自由语音聊天。
