## 现在可以使用的体验分享文案

做了一个“麦麦一起点”的交互原型，面向培智学校学生和陪伴他们的家长、老师。

孩子可以看图片、听名称，慢慢选自己想吃什么，也可以说这次先不选。家长接过清单，再一起核对。

它目前是公开演示，点选不会创建真实订单；本机版已接入真实门店、菜单和官方核价。欢迎实际点一遍，告诉我哪一步不够清楚。如果你觉得这个方向值得试，也欢迎在 GitHub 点个 Star 支持。

体验：https://littlebordercollie.github.io/mcd-together-order/
仓库：https://github.com/littlebordercollie/mcd-together-order
